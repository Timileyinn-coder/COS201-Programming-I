## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables.
- Use appropriate primitive and reference data types.
- Perform arithmetic calculations.
- Read keyboard input using Scanner.
- Display formatted output.
- Compile, test and submit Java programs using GitHub.

### Programs
1. `week03/SimpleCalculator.java` - Accepts two numbers and calculates their sum, difference, product and quotient. It also checks for division by zero.
2. `week03/AverageCalculator.java` - Accepts a student's name and three scores, then calculates and displays the total and average.
3. `week03/ItemCost.java` - Accepts an item name, quantity and unit price, then calculates and displays the total cost.

### How to Run

Open a terminal in the `week03` folder.

**SimpleCalculator.java**
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

**AverageCalculator.java**
```bash
javac AverageCalculator.java
java AverageCalculator
```

**ItemCost.java**
```bash
javac ItemCost.java
java ItemCost
```
