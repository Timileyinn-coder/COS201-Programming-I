# Week 3: Variables, Data Types, Expressions and Input/Output

## Objectives

- Declare and initialize Java variables.
- Use appropriate primitive and reference data types.
- Perform arithmetic calculations.
- Accept keyboard input using Scanner.
- Display formatted output.
- Compile and execute Java programs.

## Programs

1. **SimpleCalculator.java:** Accepts two numbers and calculates their sum, difference, product and quotient. It also checks for division by zero.

2. **AverageCalculator.java:** Accepts a student's name and three scores, then calculates and displays the total and average.

3. **ItemCost.java:** Accepts an item name, quantity and unit price, then calculates and displays the total cost.

## How to Run

Open a terminal inside the `week03` folder.

**SimpleCalculator.java**
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

**AverageCalculator.java**
```bash
javac AverageCalculator.java
java AverageCalculator
```

**ItemCost.java**
```bash
javac ItemCost.java
java ItemCost
```

## Learning Outcome

I learned how to use variables and data types, perform arithmetic calculations, accept keyboard input using Scanner and display formatted output.
